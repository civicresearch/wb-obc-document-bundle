Maintainer tool for the research datasets behind the site. Changes are saved as the same JSON files the site loads — nothing here edits the live site directly. Internal tool: back to the archive.

1 · Load the data

Website mode reads the JSON published with this site (works on GitHub Pages — good for reviewing and preparing changes). Folder mode reads and writes your local repository clone directly (Chrome/Edge, needs the repo downloaded).

3 · Validate

Runs the same structural rules as scripts/validate-data.js: required fields, duplicate ids, enum values, and the 66-class list size. Linked-file existence is checked separately because it needs requests.
