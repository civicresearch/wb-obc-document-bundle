Framework for New & Missing Entries

Use structured fields, evidence checks, status labels, and cross-links when adding new PDFs, orders, hearings, court records, reports, or missing sources.

Use this structure whenever a new PDF, court order, hearing notice, report, or missing source is added. The goal is to keep every entry searchable, source-linked, and auditable.

1. Minimum fields for every document

  • Date: ISO format, for example 2025-06-03.
  • Document number: notification/order/memo/case number exactly as printed.
  • Document type: notification, order, corrigendum, hearing notice, court order, report, act, roster, certificate guideline.
  • Status: current, withdrawn, superseded, legacy, missing, draft, or verification-needed.
  • Short summary: one sentence describing legal or documentary effect.
  • Source: published PDF URL plus source authority, when known.

2. Evidence checks before marking complete

  • Does the PDF text match the notification number, date, and printed title?
  • Does it add, amend, withdraw, classify, or merely implement another document?
  • What earlier document does it cite, and what later document changes it?
  • For inclusion/categorisation: is there a Commission advice, survey, hearing, or benchmark record?
  • For court records: what operative direction affects the current list or reservation percentage?

3. Missing-entry statuses

  • Not yet archived: known source exists, file not yet added.
  • Source not found: cited in another record, original PDF not located.
  • Partial: source found only as quote, mirror, OCR, or bundled page inside another PDF.
  • Needs OCR: scanned source exists but text is not searchable.
  • Verification needed: source exists but date/number/content conflict needs checking.
